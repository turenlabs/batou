Detection

What it catches

SQL injection, XSS, path traversal, hardcoded secrets, SSRF, and 40 more categories. Here's how it looks in practice.

Blocked — SQL injection (taint-confirmed)
func getUser(w http.ResponseWriter, r *http.Request) { id := r.URL.Query().Get("id") db.Query("SELECT * FROM users WHERE id = " + id) }
Safe — parameterized query
func getUser(w http.ResponseWriter, r *http.Request) { id := r.URL.Query().Get("id") db.Query("SELECT * FROM users WHERE id = $1", id) }
Blocked — XSS (AST + taint)
const Profile = ({ user }) => { return <div dangerouslySetInnerHTML={{ __html: user.bio }} /> }
Hint — hardcoded secret (regex-only)
# Low confidence — could be a placeholder config = { "api_key": "sk-proj-abc123..." }

False positive suppression

Suppress when you know better

Inline directives let you silence findings for safe code. Target by rule ID, category, or suppress all. Always include a reason.

// batou:ignore BATOU-INJ-001 -- query uses parameterized input
db.Query("SELECT * FROM users WHERE id = " + id)

# batou:ignore secrets -- test fixture, not a real credential
password = "test-password-for-ci"

// batou:ignore-start injection
rows := db.Query(dynamicSQL)
process(rows)
// batou:ignore-end
Installation

Up and running in seconds

One command installs the binary. Add --setup to auto-configure hooks for a project.

Terminal
# Quick install curl -fsSL https://raw.githubusercontent.com/turenlabs/batou/main/install.sh | bash # Install + configure hooks for a project curl -fsSL https://raw.githubusercontent.com/turenlabs/batou/main/install.sh | bash -s -- --setup /path/to/project # Or install globally curl -fsSL https://raw.githubusercontent.com/turenlabs/batou/main/install.sh | bash -s -- --global # Build from source (requires Go 1.21+, CGo) git clone https://github.com/turenlabs/batou.git && cd batou && make build && make install
